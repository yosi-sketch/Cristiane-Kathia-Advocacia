# Rodrigues de Carvalho Advogados

Site institucional de serviços jurídicos em Manhumirim, Minas Gerais.

## Executar

- Desenvolvimento: npm run dev -- --port 3008
- Produção: npm run build e npm run start -- --port 3009
- Verificação: npm run lint -- app

Next.js 16.3.5, React 19.2.8 e Tailwind CSS 4. Leia AGENTS.md e os guias em node_modules/next/dist/docs antes de alterar APIs do Next.js.
